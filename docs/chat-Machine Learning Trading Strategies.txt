## **Training Strategy: Beyond Simple Supervised Learning**

### **The Core Problem with "Next 15 Bars" Supervision**
Using raw price movements as labels creates several critical issues:
- **Look-ahead bias**: Models learn to predict noise rather than exploitable edges
- **Transaction cost blindness**: Ignores slippage, fees, and market impact
- **Risk ignorance**: Doesn't account for drawdowns or volatility regimes
- **Signal ambiguity**: A 0.5% move up doesn't necessarily mean "buy"

### **Superior Training Frameworks**

**1. Reinforcement Learning (RL) Approach**
This is the gold standard for signal generation training:

```python
class TradingEnvironment(gym.Env):
    def __init__(self, data, initial_capital=10000):
        self.data = data
        self.capital = initial_capital
        self.position = 0  # -1: short, 0: flat, 1: long
    
    def step(self, action):
        # Execute action (buy/sell/hold)
        reward = self._calculate_reward(action)
        # Reward = Risk-adjusted return + transaction cost penalty
        # + drawdown penalty + volatility adjustment
        return next_state, reward, done, info
    
    def _calculate_reward(self, action):
        # Sophisticated reward function
        pnl = self._calculate_pnl()
        sharpe_ratio = self._rolling_sharpe(21)  # 21-day rolling Sharpe
        max_drawdown = self._calculate_max_drawdown()
        
        # Composite reward
        reward = (
            pnl * 0.6 + 
            sharpe_ratio * 0.25 + 
            (1 - max_drawdown) * 0.15 -
            transaction_costs * 2.0  # Heavy penalty for overtrading
        )
        return reward
```

**Key RL Advantages:**

### **Signal Label Generation: The Smart Way**

Instead of trying to label "buy/sell" directly, generate optimal actions using:

**1. Optimal F Controller (Kelly Criterion)**
```python
def generate_optimal_signals(price_series, lookback=21):
    # Calculate optimal position sizing using Kelly-inspired formula
    returns = price_series.pct_change()
    win_rate = (returns > 0).rolling(lookback).mean()
    avg_win = returns[returns > 0].rolling(lookback).mean()
    avg_loss = abs(returns[returns < 0]).rolling(lookback).mean()
    
    # Kelly fraction with risk adjustment
    kelly_f = win_rate - ((1 - win_rate) / (avg_win / avg_loss))
    kelly_f = np.clip(kelly_f * 0.5, -1, 1)  # Half-Kelly for safety
    
    # Convert to discrete signals with confidence thresholds
    signals = np.zeros_like(kelly_f)
    signals[kelly_f > 0.3] = 1    # Strong buy
    signals[kelly_f < -0.3] = -1  # Strong sell
    return signals
```

```python
        if len(self.performance_history) < self.window_size * 2:
            self.performance_history.append(current_performance)
            return False
        
        # Statistical test for performance degradation
        recent = self.performance_history[-self.window_size:]
        historical = self.performance_history[:-self.window_size]
        
        # Mann-Whitney U test for non-parametric comparison
        _, p_value = stats.mannwhitneyu(recent, historical)
        
        if p_value < 0.05 and np.mean(recent) < np.mean(historical) * 0.8:
            return True  # Significant performance degradation detected
        
        self.performance_history.append(current_performance)
        return False
```

```python
        doy_returns = asset_data.groupby(asset_data.index.dayofyear)['returns'].mean()
        doy_smoothed = doy_returns.rolling(5, center=True, min_periods=1).mean()
```

### **Multi-Asset Portfolio Optimization**

**Risk-Aware Allocation:**
```python
class PortfolioOptimizationHead(nn.Module):
    def __init__(self, num_assets):
        super().__init__()
        self.num_assets = num_assets
        
        # Risk models
        self.volatility_model = VolatilityForecaster(num_assets)
        self.correlation_model = CorrelationForecaster(num_assets)
        self.tail_risk_model = TailRiskEstimator(num_assets)
        
        # Allocation network
        self.allocation_net = nn.Sequential(
            nn.Linear(256 + num_assets * 3, 128),  # Features + risk metrics
            nn.ReLU(),
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.Linear(64, num_assets),
            nn.Softmax(dim=1)  # Portfolio weights sum to 1
        )
    
    def forward(self, features, risk_context):
        # Risk forecasting
        volatility_forecast = self.volatility_model(risk_context)
        correlation_forecast = self.correlation_model(risk_context)
        tail_risk_forecast = self.tail_risk_model(risk_context)
        
        # Risk metrics integration
        risk_metrics = torch.cat([
            volatility_forecast,
            correlation_forecast.flatten(1),
            tail_risk_forecast
        ], dim=1)
        
        # Combined features
        combined_features = torch.cat([features, risk_metrics], dim=1)
        
        # Portfolio allocation
        allocation = self.allocation_net(combined_features)
        
        # Risk budget constraints
        allocation = self.apply_risk_budgets(allocation, risk_context)
        
        return allocation
    
    def apply_risk_budgets(self, allocation, risk_context):
        """Apply dynamic risk budgets based on market conditions"""
        max_risk_per_asset = risk_context['risk_budget']  # e.g., 0.2 for 20% max per asset
        max_sector_exposure = risk_context['sector_budgets']  # e.g., {'tech': 0.4}
        
        # Sector-level constraints
        sector_allocations = self.get_sector_allocations(allocation, risk_context)
        constrained_allocation = allocation.clone()
        
        for sector, max_exposure in max_sector_exposure.items():
            if sector_allocations[sector] > max_exposure:
                scale_factor = max_exposure / sector_allocations[sector]
                constrained_allocation = self.scale_sector_allocation(
                    constrained_allocation, sector, scale_factor
                )
        
        # Individual asset constraints
        constrained_allocation = torch.clamp(constrained_allocation, 0, max_risk_per_asset)
        
        # Renormalize
        constrained_allocation = constrained_allocation / constrained_allocation.sum()
        
        return constrained_allocation
```

```python
# File: data_pipeline.py
import yfinance as yf
import pandas as pd
import sqlite3
from datetime import datetime, timedelta

def setup_database():
    """Create SQLite database schema"""
    conn = sqlite3.connect('trading_data.db')
    cursor = conn.cursor()
    
    cursor.execute('''
        CREATE TABLE IF NOT EXISTS ohlcv_data (
            timestamp DATETIME PRIMARY KEY,
            symbol TEXT,
            open REAL,
            high REAL,
            low REAL,
            close REAL,
            volume REAL,
            ema_fast REAL,
            ema_slow REAL,
            rsi_14 REAL,
            atr_14 REAL,
            volatility REAL,
            vpoc REAL
        )
    ''')
    
    cursor.execute('''
        CREATE INDEX IF NOT EXISTS idx_symbol_timestamp 
        ON ohlcv_data (symbol, timestamp)
    ''')
    
    conn.commit()
    return conn

def fetch_and_process_data(symbol='SPY', interval='15m', period='60d'):
    """Fetch data and compute technical features"""
    # Fetch raw data
    df = yf.download(symbol, interval=interval, period=period)
    
    # Compute technical features
    df = compute_technical_features(df)
    
    # Add volume profile (simplified version for MVP)
    df = compute_volume_profile(df, window=20)
    
    # Add seasonality features
    df = add_seasonality_features(df)
    
    # Save to database
    conn = setup_database()
    df.to_sql('ohlcv_data', conn, if_exists='replace')
    
    return df

def compute_technical_features(df):
    """Calculate core technical indicators"""
    # EMA fast/slow
    df['ema_fast'] = df['Close'].ewm(span=8, adjust=False).mean()
    df['ema_slow'] = df['Close'].ewm(span=21, adjust=False).mean()
    
    # RSI
    delta = df['Close'].diff()
    gain = delta.where(delta > 0, 0)
    loss = -delta.where(delta < 0, 0)
    avg_gain = gain.rolling(14).mean()
    avg_loss = loss.rolling(14).mean()
    rs = avg_gain / avg_loss
    df['rsi_14'] = 100 - (100 / (1 + rs))
    
    # ATR
    high_low = df['High'] - df['Low']
    high_close = abs(df['High'] - df['Close'].shift())
    low_close = abs(df['Low'] - df['Close'].shift())
    ranges = pd.concat([high_low, high_close, low_close], axis=1)
    true_range = ranges.max(axis=1)
    df['atr_14'] = true_range.rolling(14).mean()
    
    # Volatility
    df['volatility'] = df['Close'].pct_change().rolling(20).std()
    
    return df.dropna()

def compute_volume_profile(df, window=20):
    """Simplified volume profile for MVP"""
    # For MVP, use price levels with highest volume over window
    vpoc_values = []
    
    for i in range(len(df)):
        if i < window:
            vpoc_values.append(df['Close'].iloc[i])
            continue
            
        window_data = df.iloc[i-window:i]
        price_levels = pd.cut(window_data['Close'], bins=20)
        volume_by_level = window_data.groupby(price_levels)['Volume'].sum()
        max_volume_level = volume_by_level.idxmax()
        
        # Get midpoint of the price level with max volume
        level_midpoint = (max_volume_level.left + max_volume_level.right) / 2
        vpoc_values.append(level_midpoint)
    
    df['vpoc'] = vpoc_values
    return df

def add_seasonality_features(df):
    """Add day of week and day of year features"""
    df['dow'] = df.index.dayofweek
    df['doy'] = df.index.dayofyear
    return df

# Run initial data fetch
if __name__ == "__main__":
    data = fetch_and_process_data()
    print(f"Data pipeline complete. Shape: {data.shape}")
    print(f"Latest data point: {data.index[-1]}")
```

```python
# File: trading_model.py
import torch
import torch.nn as nn
import torch.nn.functional as F
import numpy as np

class MultiScaleTradingModel(nn.Module):
    def __init__(self, input_dim=10, hidden_dim=64):
        super().__init__()
        
        # Input projection
        self.input_proj = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU()
        )
        
        # Multi-scale feature extractors
        # Daily scale (3 hours = 12 x 15min bars)
        self.daily_conv = nn.Sequential(
            nn.Conv1d(hidden_dim, hidden_dim//2, kernel_size=12, padding=6),
            nn.BatchNorm1d(hidden_dim//2),
            nn.ReLU(),
            nn.AdaptiveAvgPool1d(1)
        )
        
        # Weekly scale (1 day = 96 x 15min bars)
        self.weekly_conv = nn.Sequential(
            nn.Conv1d(hidden_dim, hidden_dim//2, kernel_size=96, padding=48),
            nn.BatchNorm1d(hidden_dim//2),
            nn.ReLU(),
            nn.AdaptiveAvgPool1d(1)
        )
        
        # Monthly scale (5 days = 480 x 15min bars)
        self.monthly_conv = nn.Sequential(
            nn.Conv1d(hidden_dim, hidden_dim//2, kernel_size=480, padding=240),
            nn.BatchNorm1d(hidden_dim//2),
            nn.ReLU(),
            nn.AdaptiveAvgPool1d(1)
        )
        
        # Feature fusion
        self.fusion = nn.Sequential(
            nn.Linear(hidden_dim//2 * 3, hidden_dim),
            nn.ReLU(),
            nn.Dropout(0.3)
        )
        
        # Dual output heads
        self.signal_head = nn.Sequential(
            nn.Linear(hidden_dim, 32),
            nn.ReLU(),
            nn.Linear(32, 3)  # Buy/Hold/Sell probabilities
        )
        
        self.forecast_head = nn.Sequential(
            nn.Linear(hidden_dim, 64),
            nn.ReLU(),
            nn.Linear(64, 15)  # Next 15 bars forecast
        )
    
    def forward(self, x):
        """
        x shape: (batch_size, sequence_length, input_dim)
        """
        batch_size, seq_len, _ = x.shape
        
        # Project input features
        x_proj = self.input_proj(x)  # (batch_size, seq_len, hidden_dim)
        
        # Reshape for convolution: (batch_size, hidden_dim, seq_len)
        x_conv = x_proj.permute(0, 2, 1)
        
        # Multi-scale feature extraction
        daily_features = self.daily_conv(x_conv).view(batch_size, -1)
        weekly_features = self.weekly_conv(x_conv).view(batch_size, -1)
        monthly_features = self.monthly_conv(x_conv).view(batch_size, -1)
        
        # Feature fusion
        fused_features = torch.cat([daily_features, weekly_features, monthly_features], dim=1)
        fused_features = self.fusion(fused_features)
        
        # Output heads
        signals = self.signal_head(fused_features)
        forecast = self.forecast_head(fused_features)
        
        return {
            'signal_probs': F.softmax(signals, dim=1),
            'price_forecast': forecast
        }

def prepare_training_data(df, sequence_length=504):  # 504 = 21 days of 15min bars
    """Prepare data for training the model"""
    # Select features for training
    features = [
        'Close', 'Volume', 'ema_fast', 'ema_slow', 'rsi_14', 
        'atr_14', 'volatility', 'vpoc', 'dow', 'doy'
    ]
    
    # Normalize features
    X = df[features].values
    X_norm = (X - X.mean(axis=0)) / (X.std(axis=0) + 1e-8)
    
    # Prepare sequences
    X_seq = []
    y_signal = []
    y_forecast = []
    
    for i in range(len(X_norm) - sequence_length - 15):
        # Input sequence
        seq = X_norm[i:i+sequence_length]
        X_seq.append(seq)
        
        # Signal target: 1 if price goes up 0.5% in next 3 bars, -1 if down 0.5%, 0 otherwise
        future_prices = df['Close'].iloc[i+sequence_length:i+sequence_length+3].values
        current_price = df['Close'].iloc[i+sequence_length-1]
        
        max_gain = (future_prices.max() - current_price) / current_price
        max_loss = (future_prices.min() - current_price) / current_price
        
        if max_gain > 0.005:
            signal = 2  # Buy
        elif max_loss < -0.005:
            signal = 0  # Sell
        else:
            signal = 1  # Hold
        y_signal.append(signal)
        
        # Forecast target: normalized returns for next 15 bars
        forecast_prices = df['Close'].iloc[i+sequence_length:i+sequence_length+15].values
        forecast_returns = np.diff(forecast_prices) / forecast_prices[:-1]
        forecast_returns = np.pad(forecast_returns, (0, 16-len(forecast_returns)), 'constant')[:15]
        y_forecast.append(forecast_returns)
    
    return (
        torch.tensor(np.array(X_seq), dtype=torch.float32),
        torch.tensor(np.array(y_signal), dtype=torch.long),
        torch.tensor(np.array(y_forecast), dtype=torch.float32)
    )

# Test model architecture
if __name__ == "__main__":
    sample_input = torch.randn(32, 504, 10)  # batch_size=32, sequence_length=504, input_dim=10
    model = MultiScaleTradingModel(input_dim=10)
    outputs = model(sample_input)
    
    print("Model architecture ready!")
    print(f"Signal output shape: {outputs['signal_probs'].shape}")
    print(f"Forecast output shape: {outputs['price_forecast'].shape}")
```

```python
    val_size = int(0.2 * len(X_seq))
    
    X_train, X_val, X_test = X_seq[:train_size], X_seq[train_size:train_size+val_size], X_seq[train_size+val_size:]
    y_signal_train, y_signal_val, y_signal_test = y_signal[:train_size], y_signal[train_size:train_size+val_size], y_signal[train_size+val_size:]
    y_forecast_train, y_forecast_val, y_forecast_test = y_forecast[:train_size], y_forecast[train_size:train_size+val_size], y_forecast[train_size+val_size:]
    
    # Create datasets and dataloaders
    train_dataset = TensorDataset(X_train, y_signal_train, y_forecast_train)
    val_dataset = TensorDataset(X_val, y_signal_val, y_forecast_val)
    
    train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)
    val_loader = DataLoader(val_dataset, batch_size=32, shuffle=False)
    
    # Initialize model
    model = MultiScaleTradingModel(input_dim=10)
    device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
    model = model.to(device)
    
    # Loss functions
    signal_criterion = nn.CrossEntropyLoss()
    forecast_criterion = nn.MSELoss()
    
    # Optimizer
    optimizer = optim.Adam(model.parameters(), lr=0.001)
    scheduler = optim.lr_scheduler.ReduceLROnPlateau(optimizer, 'min', patience=3, factor=0.5)
    
    # Training loop
    num_epochs = 25
    best_val_loss = float('inf')
    train_losses = []
    val_losses = []
    
    for epoch in range(num_epochs):
        # Training phase
        model.train()
        train_loss = 0.0
        
        for X_batch, y_signal_batch, y_forecast_batch in tqdm(train_loader, desc=f"Epoch {epoch+1}/{num_epochs}"):
            X_batch = X_batch.to(device)
            y_signal_batch = y_signal_batch.to(device)
            y_forecast_batch = y_forecast_batch.to(device)
            
            optimizer.zero_grad()
            
            outputs = model(X_batch)
            signal_loss = signal_criterion(outputs['signal_probs'], y_signal_batch)
            forecast_loss = forecast_criterion(outputs['price_forecast'], y_forecast_batch)
            
            # Combined loss (70% signal, 30% forecast)
            loss = 0.7 * signal_loss + 0.3 * forecast_loss
            loss.backward()
            optimizer.step()
            
            train_loss += loss.item()
        
        avg_train_loss = train_loss / len(train_loader)
        train_losses.append(avg_train_loss)
        
        # Validation phase
        model.eval()
        val_loss = 0.0
        
        with torch.no_grad():
            for X_batch, y_signal_batch, y_forecast_batch in val_loader:
                X_batch = X_batch.to(device)
                y_signal_batch = y_signal_batch.to(device)
                y_forecast_batch = y_forecast_batch.to(device)
                
                outputs = model(X_batch)
                signal_loss = signal_criterion(outputs['signal_probs'], y_signal_batch)
                forecast_loss = forecast_criterion(outputs['price_forecast'], y_forecast_batch)
                
                loss = 0.7 * signal_loss + 0.3 * forecast_loss
                val_loss += loss.item()
        
        avg_val_loss = val_loss / len(val_loader)
        val_losses.append(avg_val_loss)
        
        print(f"Epoch {epoch+1}/{num_epochs}, Train Loss: {avg_train_loss:.4f}, Val Loss: {avg_val_loss:.4f}")
        
        # Learning rate scheduling
        scheduler.step(avg_val_loss)
        
        # Save best model
        if avg_val_loss < best_val_loss:
            best_val_loss = avg_val_loss
            torch.save(model.state_dict(), 'best_trading_model.pth')
            print("Saved new best model")
    
    # Plot training history
    plt.figure(figsize=(10, 6))
    plt.plot(train_losses, label='Training Loss')
    plt.plot(val_losses, label='Validation Loss')
    plt.title('Model Training History')
    plt.xlabel('Epoch')
    plt.ylabel('Loss')
    plt.legend()
    plt.savefig('training_history.png')
    plt.close()
    
    # Load best model
    model.load_state_dict(torch.load('best_trading_model.pth'))
    return model, X_test, y_signal_test, y_forecast_test

# Run training

    trained_model, X_test, y_signal_test, y_forecast_test = train_model()
```

```python
# File: signal_generation.py
import torch
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from trading_model import MultiScaleTradingModel
from data_pipeline import fetch_and_process_data
import sqlite3
from datetime import datetime, timedelta

class SignalGenerator:
    def __init__(self, model_path='best_trading_model.pth'):
        self.model = MultiScaleTradingModel(input_dim=10)
        self.device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
        self.model.load_state_dict(torch.load(model_path))
        self.model = self.model.to(self.device)
        self.model.eval()
        self.sequence_length = 504  # 21 days of 15min bars
    
    def generate_signals(self, symbol='SPY', interval='15m', period='7d'):
        """Generate trading signals for the last week of data"""
        # Fetch and process latest data
        df = fetch_and_process_data(symbol, interval, period)
        
        # Prepare features
        features = [
            'Close', 'Volume', 'ema_fast', 'ema_slow', 'rsi_14', 
            'atr_14', 'volatility', 'vpoc', 'dow', 'doy'
        ]
        
        # Normalize features using rolling statistics
        X = df[features].values
        rolling_mean = pd.DataFrame(X, columns=features).rolling(50).mean().values
        rolling_std = pd.DataFrame(X, columns=features).rolling(50).std().values
        
        X_norm = (X - rolling_mean) / (rolling_std + 1e-8)
        X_norm = np.nan_to_num(X_norm)
        
        # Generate signals for each timepoint
        signals = []
        forecasts = []
        signal_probs = []
        
        for i in range(self.sequence_length, len(X_norm)):
            seq = X_norm[i-self.sequence_length:i]
            seq_tensor = torch.tensor(seq, dtype=torch.float32).unsqueeze(0).to(self.device)
            
            with torch.no_grad():
                outputs = self.model(seq_tensor)
            
            # Get signal
            probs = outputs['signal_probs'].cpu().numpy()[0]
            signal = np.argmax(probs)
            signals.append(signal)
            signal_probs.append(probs)
            
            # Get forecast (normalized returns)
            forecast = outputs['price_forecast'].cpu().numpy()[0]
            forecasts.append(forecast)
        
        # Add signals to dataframe
        df_result = df.iloc[self.sequence_length:].copy()
        df_result['signal'] = signals
        df_result['signal_prob_buy'] = [p[2] for p in signal_probs]
        df_result['signal_prob_sell'] = [p[0] for p in signal_probs]
        df_result['forecast'] = forecasts
        
        # Convert forecast to price levels
        df_result['forecast_prices'] = df_result.apply(
            lambda row: self._convert_forecast_to_prices(row['forecast'], row['Close']), 
            axis=1
        )
        
        return df_result
    
    def _convert_forecast_to_prices(self, forecast_returns, current_price):
        """Convert normalized returns to price levels"""
        # Simple conversion for MVP
        prices = [current_price]
        for ret in forecast_returns:
            prices.append(prices[-1] * (1 + ret * 0.01))  # Scale returns for visualization
        return prices[1:]

def vectorized_backtest(signals_df, initial_capital=10000, commission=0.001):
    """Fast vectorized backtesting"""
    df = signals_df.copy()
    
    # Calculate daily returns
    df['returns'] = df['Close'].pct_change()
    
    # Position sizing (simplified)
    df['position'] = 0
    df.loc[df['signal'] == 2, 'position'] = 1  # Buy
    df.loc[df['signal'] == 0, 'position'] = -1  # Sell
    df.loc[df['signal'] == 1, 'position'] = 0  # Hold
    
    # Shift positions to avoid look-ahead bias
    df['position'] = df['position'].shift(1).fillna(0)
    
    # Calculate strategy returns
    df['strategy_returns'] = df['position'] * df['returns']
    
    # Calculate transaction costs
    df['position_change'] = df['position'].diff().abs()
    df['transaction_costs'] = df['position_change'] * commission
    
    # Net returns after costs
    df['net_returns'] = df['strategy_returns'] - df['transaction_costs']
    
    # Calculate equity curve
    df['cum_return'] = (1 + df['net_returns']).cumprod()
    df['equity'] = initial_capital * df['cum_return']
    
    # Calculate buy & hold returns for comparison
    df['buy_hold_return'] = (1 + df['returns']).cumprod()
    df['buy_hold_equity'] = initial_capital * df['buy_hold_return']
    
    # Performance metrics
    total_return = df['cum_return'].iloc[-1] - 1
    sharpe_ratio = df['net_returns'].mean() / df['net_returns'].std() * np.sqrt(252*6.5)  # Annualized for 15min data
    
    metrics = {
        'total_return': total_return,
        'sharpe_ratio': sharpe_ratio,
        'final_equity': df['equity'].iloc[-1],
        'max_drawdown': (df['equity'] / df['equity'].cummax() - 1).min()
    }
    
    return df, metrics

# Example usage
if __name__ == "__main__":
```

```python
                # Step 5: Save results
                results_file = os.path.join(self.results_dir, f'{symbol}_results_{datetime.now().strftime("%Y%m%d")}.csv')
                backtest_df.to_csv(results_file)
                
                results[symbol] = {
                    'metrics': metrics,
                    'visualization': viz_path,
                    'results_file': results_file,
                    'latest_signal': int(signals_df['signal'].iloc[-1]),
                    'signal_confidence': {

        """Setup scheduled pipeline runs"""
        # Run daily at market close (4:00 PM ET)

        self.setup_scheduled_updates()
        
        logger.info("Starting pipeline scheduler...")
        while True:
            schedule.run_pending()
            time.sleep(60)  # Check every minute

                'hold': 1.0 - float(latest['signal_prob_buy']) - float(latest['signal_prob_sell'])
            },
            'price': float(latest['Close']),
            'timestamp': latest.name.isoformat(),
            'forecast': latest['forecast_prices'][:5]
        })
    except Exception as e:
        return jsonify({'error': str(e)}), 500
```
